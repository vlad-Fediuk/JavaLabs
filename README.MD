# Student Journal

Консольний застосунок для ведення студентського журналу. Програма зберігає список студентів у пам’яті, дозволяє додавати оцінки й відвідування, переглядати статистику, сортувати студентів за середнім балом та здійснювати пошук із комплексною обробкою виняткових ситуацій (Лабораторна робота №3).

## Можливості

- додавання студентів із ПІБ і групою;
- перегляд списку всіх студентів;
- додавання оцінок від 0 до 100 із зазначенням предмета, дати й типу роботи;
- перегляд усіх оцінок конкретного студента;
- фіксація та перегляд відвідування;
- розрахунок середнього бала й кількості відвіданих занять;
- сортування студентів за середнім балом методом Bubble Sort;
- підрахунок студентів із середнім балом не нижче 60;
- пошук студента за ПІБ і групою;
- зміна поточної дати через секретну команду `SecretNextDay`;
- надійна обробка помилок та валідація (ЛР №3):
  - перехоплення некоректного введення (`NumberFormatException`);
  - перевірка меж списків та масивів (`IndexOutOfBoundsException`);
  - ієрархія власних винятків (`JournalException`, `InvalidGradeException`, `StudentNotFoundException`);
  - гарантоване виконання блоків `finally` для аудиту операцій;
  - демонстрація механізму повторного збудження винятків (`re-throw`).

Дані зберігаються тільки під час роботи програми. Після завершення застосунку список студентів, оцінки та відвідування не зберігаються у файлах або базі даних.

## Ієрархія винятків (ЛР №3)

```text
java.lang.Exception (checked)
    └── JournalException (базовий клас доменних помилок журналу)
            ├── InvalidGradeException (порушення діапазону оцінки 0–100, зберігає invalidScore)
            └── StudentNotFoundException (студента не знайдено, зберігає searchTarget)
```

## Структура проєкту

```text
src/
├── Attendance.java              # Запис про відвідування
├── Grade.java                   # Окрема оцінка з валідацією балу
├── Student.java                 # Студент, його оцінки та відвідування
├── Main.java                    # Меню, консольний інтерфейс та обробка винятків
├── JournalException.java        # Базовий checked-виняток для доменних помилок
├── InvalidGradeException.java   # Виняток для некоректного значення оцінки
└── StudentNotFoundException.java # Виняток у разі відсутності студента
```

## Вимоги

- Java Development Kit (JDK) 17 або новіший (перевірено на JDK 25);
- PowerShell або інший термінал;
- кодування файлів і консолі UTF-8 для коректного відображення кирилиці.

Перевірити встановлену версію Java можна командами:

```powershell
java --version
javac --version
```

## Запуск у Windows PowerShell

Виконуйте команди з кореня проєкту — з папки, у якій розташовані `README.MD` і `src`.

### 1. Увімкнути UTF-8 для поточної сесії PowerShell

```powershell
chcp 65001
$OutputEncoding = [Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
```

### 2. Скомпілювати програму

```powershell
Remove-Item -Recurse -Force out -ErrorAction SilentlyContinue
javac -encoding UTF-8 -d out src\*.java
```

### 3. Запустити програму

```powershell
java -cp out Main
```

## Як користуватися

Після запуску введіть поточну дату у форматі `дд.мм.рр`, наприклад `20.09.26`. Далі працюйте через меню:

```text
1 — додати студента
2 — показати всіх студентів
3 — додати оцінку
4 — показати оцінки студента
5 — додати відвідування
6 — показати відвідування студента
7 — відсортувати студентів за середнім балом
8 — показати підсумок за порогом 60 балів
9 — знайти студента
0 — завершити роботу
```

Для поля відвідування можна вводити `true` / `false`, `так` / `ні`, `1` / `0` або `+` / `-`. Десятковий бал можна вводити як через крапку, так і через кому: `74.5` або `74,5`.
